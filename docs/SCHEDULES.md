# 定时任务

定时任务由本地 Agent 运行时负责调度，任务数据保存在 Agent 数据目录的 `.agent/schedules.json`。运行时启动后会恢复任务，按本机时间计算下一次执行时间；不依赖系统级 cron 或云端服务。

每次触发都会创建一个新的会话，并把提示词作为该会话的第一条消息运行。会话、工具调用和最终摘要仍然使用现有的 JSONL 会话存储，因此可以像普通会话一样回放。任务同时保留最近的运行记录，记录执行状态、错误、工作区和会话 ID。

目前支持单次、每天、每周和按分钟间隔执行。任务可以选择已登记的工作空间和执行权限。运行时发现有其它会话正在执行时会暂缓本次触发，等待空闲后再重试；应用重启时，未完成的运行会标记为运行时中断，避免界面一直显示“运行中”。

定时任务入口位于工作台侧边栏的“定时任务”，可创建、编辑、暂停、恢复、立即运行和删除任务，也可以查看运行记录。调度属于本地能力，任务提示词和运行结果不会自动上传到第三方服务之外的额外位置；模型请求仍遵循当前服务商配置和权限策略。
