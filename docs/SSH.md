# SSH 远程工作区

当前实现可将 Linux SSH 主机上的项目目录登记为工作区。切换后，终端、文件目录和文本读写、Agent 的基础文件工具与 `bash`、主机状态采样、Git 状态与 remote 管理都面向同一远端目录。工作区代码留在服务器；MLI 会话数据保存在本机独立目录。

## 添加和信任服务器

1. 打开“终端”，选择“管理 SSH 服务器”。
2. 填写名称、主机、端口、用户名和认证方式。支持本机 SSH Agent、由系统文件选择器选取的私钥文件，或服务器登录密码。已有连接可在详情的“认证方式”中修改并保存。
3. 保存后先检查服务器指纹，并通过服务器控制台或管理员提供的可信渠道核对。
4. 指纹正确后连接。MLI 会固定已确认指纹；后续指纹变化会阻止连接。

私钥文件保留在本机。私钥口令仅用于当次连接；登录密码可以在新增时输入，并选择使用系统安全存储加密记住，不写入连接配置。私钥口令用于解锁私钥，与服务器登录密码不能混用。密码认证要求服务器允许该用户使用 SSH password 登录。默认关闭 SSH Agent forwarding、TCP forwarding 和 X11 forwarding。

## 使用远程工作区

连接成功后，在 SSH 服务器设置远程项目目录，再选择“添加为项目工作区”。从工作区列表切换到该目录后，文件面板通过 SFTP 工作，Agent 的文本文件工具和搜索访问远端项目；Agent `bash` 与交互式终端以 SSH 用户身份在远端执行。切换工作区会话保存在对应的本机目录。

连接管理中可以查看服务器 CPU、内存、负载和项目所在盘容量。面板显示最近一次只读采样，打开管理窗口时每 5 秒刷新，不能作为高精度或告警监控。

文件目录工具栏的 Git 面板适用于本机和 SSH 工作区，显示分支、变更文件和差异，可暂存/取消暂存、提交暂存项、切换或新建分支，以及 fetch、fast-forward-only pull 和 push，并可管理 remote。URL 支持 GitHub、GitLab、Gitee 及兼容 SSH/HTTPS 的自托管地址。SSH 工作区中的 Git 由服务器执行，使用服务器自己的 SSH Agent 或 credential helper；本机不会把 Git 密钥转发到服务器。push、pull 和分支切换需确认执行主机；切换分支/Pull 要求工作区干净，Pull 冲突时拒绝自动合并。凭据、密钥和 `.git` 元数据不能通过 Git 面板暂存；差异有大小限制。

远程 SFTP 当前支持目录浏览、文本读取/写入、创建、改名、移动和有边界的删除预检；二进制/Office/媒体预览、复制和语言服务尚未接入。受保护路径和符号链接不会通过文件 API 访问。写入有 5 MB 上限，读取有 512 KB 上限。

Agent 写入及 shell 仍按现有工具权限策略审批。远端命令使用 SSH 账号权限，不受本机命令沙箱约束；连接中断或超时后的副作用可能未知，系统不会自动重放。

切换本机/SSH 终端执行位置会先停止当前终端并重建面板会话。断开 SSH 会关闭该主机的 PTY。桌面 HTTP 服务默认绑定 loopback；SSH 管理和远程写 API 检查 socket 来源、Host、Origin 和 Fetch Metadata，拒绝非本机或跨站请求。

Git 面板提供已有仓库的基础工作流；项目“＋”提供克隆到本机并创建工作区的入口。暂不集成 PR/MR、Issue、CI、OAuth 或托管商 API。GitHub、GitLab、Gitee 和自建服务使用通用 Git SSH/HTTPS remote；真实托管认证、非快进和网络中断结果仍需真实服务验收。远程 LSP、公网/跳板环境和 Windows/Linux 安装包仍未验收。远程 shell 以 SSH 登录账号权限运行，Git 面板的路径保护不能约束用户主动在终端运行的任意 Git 命令。

分支创建/切换、staged commit、文本 diff、fetch、fast-forward-only pull、push 和 remote 管理已有本地/SSH Provider 实现。详细范围与逐条验收用例见[SSH 与 Git 集成评估](research/2026-10-28-ssh-remote-workspace-git-assessment.md)。当前包含真实临时 OpenSSH 集成测试，但不替代公网 Git 服务和跨平台安装包验收。


### 密码、一键连接和实时监控

新增连接默认使用密码认证，可以直接输入密码。“记住密码”仅在桌面系统安全存储可用时启用；不勾选时密码只用于本次连接。已有连接可以替换或清除保存的密码。

桌面主进程使用 Electron safeStorage 加密，密文保存在用户数据目录 `.security/ssh/credentials/*.enc`，文件权限为 0600，目录权限为 0700（Windows 使用当前用户的系统保护）。拒绝 Linux `basic_text` 回退，不自行生成与密文一起保存的密钥。解密仅发生在主进程，页面仅获取是否保存的状态，不提供读取明文接口。凭据绑定主机、端口、用户名和认证方式；更换目标后不会复用旧密码。删除连接同步删除密文。更换系统账户、钥匙串不可用或密文损坏时需重新输入。系统账户已被控制、管理员权限或进程内存访问不属于静态加密能阻止的范围。

点击“连接”自动完成主机身份检查，首次需确认指纹；已信任主机后续直接连接。指纹变化仍阻止登录，不能静默替换。

远程终端头部显示 CPU、内存和磁盘占用，采样完成后约 5 秒再刷新；悬浮显示容量、核数及采样时间，点击进入详情。窄窗口折叠为状态入口。关闭管理弹窗不影响头部采样，离开远程终端或断开连接会停止。基础采样使用 Linux `/proc` 和 `df`，不安装服务器常驻程序；不支持或采样失败显示不可用原因。磁盘对应项目目录所在文件系统，未设置目录时采样根文件系统。


项目列表的“＋”和会话输入框的工作目录按钮共用“添加工作目录”窗口。支持选取本地文件夹、选择已连接 SSH 服务器的真实目录，以及将 GitHub、Gitee、GitLab 或自托管 Git 仓库克隆到本机。SSH 远程工作区仍支持在 SSH 管理器中直接设置路径。Git 克隆会拒绝已有目标目录，私有仓库认证通过本机 SSH Agent 或 Git 凭据管理器完成。
