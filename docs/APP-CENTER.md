# 应用台

应用台位于侧边导航，提供桌面端的 Chromium 内置浏览器。每个应用使用独立的 `persist:mli-app-<id>` 会话，本机保存 Cookie、localStorage 和 IndexedDB；关闭工作台后仍保留登录，不需要让模型读取密码或复制 Cookie。

## 使用

应用台采用 mac 风格圆角图标卡片，支持全部应用、平台应用、我的应用筛选及名称/网址搜索。用户添加应用只需输入网址（例如 `github.com`），名称可选，自动补全 HTTPS。相同网址不会重复添加。网站图标自动发现 HTML 中的 icon / apple-touch-icon，再尝试 `/favicon.ico`；支持 PNG、JPEG、GIF、WebP 和 ICO，获取失败显示首字母。图标由本地运行时获取与缓存，不发送浏览器 Cookie，也不使用第三方图标服务。

平台应用通过已配置账户服务的公共 `/api/v2/apps` 接口同步。客户端每分钟同步，应用台右上角可立即刷新；离线时保留本机目录。平台应用只提供入口，各用户需自行登录确认授权。

平台名称或描述更新保留本机授权；网址变更会清除旧授权并要求重新登录确认，下架/删除会隐藏入口及中止相关等待/操作。站点存储继续留在本机，重新发布不会自动恢复授权。用户自建应用独立保存，不上传后台。平台应用可以管理本机登录与授权范围，发布信息由后台统一维护。

1. 在应用台添加公共 HTTPS 应用，或选择常用平台快捷入口。
2. 在内置页面中自行登录、处理验证码及平台授权。
3. 点击应用卡片上的“确认登录”。这是用户主观确认，不要求页面当前可见，也不检测登录状态。授权记录不包含 Cookie 值或密码。
4. 对 Agent 发出任务。Agent 先查询应用台，打开并核对授权，再读取页面及执行操作。未授权时会自动打开应用台，暂停当前工具调用；用户登录确认后，同一个任务继续。
5. 撤销 Agent 授权可保留用户登录；“退出并清除登录”会清除该应用的本机 Cookie 和站点存储。移除应用也会清理这些数据。

应用保存于用户数据目录 `.security/app-center/apps.json`，内部浏览器桥接令牌位于同目录。浏览器站点存储由 Electron 的隔离 session 管理。不要把用户数据目录作为代码分发内容。

## Agent 接口

- `app_list`：查询应用和授权状态。
- `app_open`：通过 app_id 或 URL 打开；新网站自动创建未授权记录，等待用户确认。登录等待上限十分钟，任务停止、撤销及超时会释放等待。
- `app_snapshot`：读取页面文字及元素 ref，不返回密码字段或浏览器存储。
- `app_action`：通过 ref 点击、填写普通字段，按键、滚动或跳转公共 HTTPS 页面，不限制业务域名。默认权限模式走 L3 审批；完全访问模式自动执行已授权应用中的操作，应用仍需完成登录确认且允许 Agent 使用。撤销权限、只读 Agent 与云端执行授权仍会拦截；发送、删除、发布必须符合用户明确指令。`type` 替换输入框或编辑器的完整内容，支持多行，使用 Chromium 编辑命令更新编辑器状态，不使用系统剪贴板。点击后元素仍在原页面时可沿用 ref 输入；新快照、导航或元素被替换后须重新获取 ref。操作后读取快照验证，过期引用、只读字段等错误会返回具体原因。

完全访问是对当前 Agent 已开放工具的通配审批，不需要逐个工具配置永久允许规则；只读任务限制、工具白名单/角色范围、命令沙箱、桌面会话显式开关和云端执行授权仍是独立边界。外部 ACP Agent 的进程启动及其发起的操作保留单次人工审批，因为外部进程不受 MLI 沙箱约束。切换为完全访问时，同一会话中等待审批的普通工具调用会自动恢复。

应用台操作直接使用该应用的登录会话，独立于 MCP 的访问令牌及读写权限。MCP token 只读不妨碍按用户授权通过已登录的应用页面操作；临时 `open_url` 标签和外部 Edge/Chrome 则不共享这个登录。

网页任务始终使用内置浏览器，不要求宿主桌面可见或开启桌面会话。页面操作失败时重新快照并修复具体错误；缺少必要浏览器能力时说明缺口，不自行切换桌面截图、系统鼠标键盘或外部浏览器。桌面工具仅用于用户明确要求的桌面软件、系统界面或外部浏览器任务；关闭桌面会话时，窗口枚举等只读桌面工具也不可用。

本地接口 `/api/app-center` 管理记录。只有 Electron 主进程携带私有令牌才可调用 `/bridge/*`，远端网站没有工作台 preload、Node 或 Electron API。浏览器与运行时之间通过受认证的任务队列桥接，结果关联调用 id。撤销后不会继续派发该应用已有排队操作。网页内容仍是不可信资料，不能覆盖用户目标及权限规则。

## 登录判断与边界

登录状态仅以用户点击“确认登录”为准，不进行 DOM 登录探测，不使用业务域名白名单或登录入口路径拦截。页面跳转不会撤销用户确认；撤销权限、清除登录、应用入口更改等显式操作仍会使授权失效。实际操作时由 Agent 根据页面判断是否需要用户重新登录。浏览器后台视图禁用节流，单次页面操作超过 15 秒返回明确错误，避免阻塞后续队列。

人工登录可跳转 OAuth 网站并打开原生弹窗；这些页面共享该应用的隔离会话。Agent 可跳转公共 HTTPS 网站，不能调用任意 JavaScript、读取 Cookie、代填密码/验证码/支付字段；自动化弹窗被阻止。远端页面的相机、麦克风、剪贴板、下载等额外系统权限默认拒绝。公共 HTTPS 检查和请求时 DNS 检查阻止常见本机/内网目标；这不是网络命名空间或防 DNS rebinding 的内核边界。

浏览器属于受信任宿主能力，使用 Chromium renderer sandbox，独立于 Agent shell 的系统沙箱。已登录不等于允许任意外发、删除、发布或购买，仍需用户任务授权及工具审批。此版本操作主文档 DOM；跨域 iframe、Canvas 应用等可能需要后续截图/视觉操作能力。平台可能限制嵌入式浏览器登录；本版本不会绕过平台要求或复制外部浏览器的登录凭据。

同一应用共享一个浏览页面，操作按应用串行执行；多个任务同时操作同一应用时，其他任务可能使页面或元素引用失效，需要重新读取快照。退出并清除登录也会关闭该应用的 OAuth 弹窗，防止弹窗再次写入登录数据。

网页端可管理应用清单；内置浏览器需要桌面端在线连接。CLI 可连接同一运行时使用应用工具，但登录需用户在桌面应用台完成。刷新前端可恢复待登录入口；完整退出运行时会中断等待，登录记录仍保留，重新启动后需要继续任务。

```powershell
node --test test/app-center*.test.mjs
```

覆盖记录持久化、未登录等待与恢复、取消/超时、跨域和本机地址拒绝、桥接认证及重放、真实 Chromium 浏览器操作与登录存储。真实浏览器测试使用自建 HTTPS 协议夹具，不使用真实平台账户。
